# 🎟️ Lottery Game

A simple lottery game built with React.

## Features
- Generate random lottery tickets.
- Display ticket numbers dynamically.
- Check winning conditions.
- Show winner or try-again messages.
- Generate new tickets.

## Tech Stack
- React
- JavaScript
- CSS
- Vite

## Concepts Practiced
- useState Hook
- Props
- Component Composition
- Lifting State Up
- Conditional Rendering
- Event Handling
- CSS Flexbox

## Purpose
Built as a practice project while learning React and improving frontend development skills.
